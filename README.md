## 🚀 Deployment

This site is automatically deployed to GitHub Pages using GitHub Actions. Any push to the `main` branch triggers a new deployment.

## 📝 How to Edit

1. Edit `index.html` to update resume content
2. Edit `styles.css` to modify styling
3. Commit and push to `main` branch
4. GitHub Actions will automatically deploy the changes

## 🛠️ Local Development

Simply open `index.html` in your browser to preview changes locally.
